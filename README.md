Comandos necesarios: npm install npm install axios npm run dev

Explicación:


BarraNavegación: este componente aparece en la parte superior de todas las páginas para ello he tenido que ponerlo en el layout. Muestra la palabra NebrijaSocial. También dispone de tres botones: Perfil que cuando interactuas con el te mete en tu perfil mostrando tus datos y posts, home que te devuelve a la pagina de inicio y logout que te saca a la pagina de login y register.

Home: esta es la pagina principal donde se pueden observar las publicaciones de los demas usuarios, comentar en las publicaciones, acceder al perfil de los usuarios que han publicado y dar like y retweet a las publicaciones. En esta página también esta incluido el input para poder poner una publicación tuya.


Comentarios: 
Esta pagina te muestra el post al que quieres comentar y el resto de comentarios puestos por otras personas. Ademas de permitirte publicar un comentario al post

Perfiles:
en la página se muestra el perfil de la persona a la que has accedido con el boton de seguir y todas las publicaciones que ha hecho.

User:
muestra tus datos y posts


login:
esta página te permite registrarte o iniciar sesion puedes elegir la opción mediante un boton, cuando inicias o registras sesion, devuelven un token que es almacenado el las cookies que luego el proxy utilizará para permitirte acceder al resto de páginas
